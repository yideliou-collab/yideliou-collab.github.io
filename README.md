# MIND Lab website

This repository contains the static GitHub Pages build of the MIND Lab website. The editable source is the Webstudio project **LabWebsite backup 2026-11-17**. Edit text, images, publications, news, and facilities in Webstudio, then export and rebuild before copying the new `dist/client` output here.

The English site is at `/`; Traditional Chinese is at `/zh/`. The language control in the Webstudio navigation switches between the two home pages.

Do not commit Webstudio share links, auth tokens, or `.webstudio/config.json` to this public repository.
